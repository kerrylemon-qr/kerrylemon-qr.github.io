# qr.kerrylemon.co.uk (hub)

This repo owns the custom domain **qr.kerrylemon.co.uk**. Each sculpture's QR site is its own repo and appears under this domain automatically:

| Sculpture | Repo | Address |
|---|---|---|
| PORTAL | `portal` | https://qr.kerrylemon.co.uk/portal/ |
| Sparrowkeepers | `sparrowkeepers` | https://qr.kerrylemon.co.uk/sparrowkeepers/ |

The root of the domain (and any unknown address) forwards to https://www.kerrylemon.co.uk/.

Repo names must be **lowercase**, because the address path is case-sensitive.

DNS: `qr` is a CNAME record pointing to `kerrylemon-qr.github.io`. This repo and the sculpture repos live in the `kerrylemon-qr` organisation, which Kerry owns.
